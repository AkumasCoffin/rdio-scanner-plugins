# Plugin API reference

Generated by Rdio Scanner 6.14.0-beta.1. Do not edit — run `rdio-scanner -plugin_docs` to regenerate.

Plugin API version: **1**

A plugin declares `"apiVersion": 1` in its manifest. The server refuses a plugin written for a newer API than it
knows, and supports one version back — so a plugin keeps working across server
updates without being rebuilt.

## The four verbs

Everything a plugin does to the server is one of these, registered against a
named extension point.

| Verb | Meaning |
|---|---|
| `rdio.on(point, fn)` | Observe. Runs asynchronously and cannot change anything. |
| `rdio.filter(point, fn)` | Modify what passes through, or veto it by returning `{drop: true}`. |
| `rdio.override(point, fn)` | Replace the server's behaviour for that point entirely. |
| `rdio.provide(point, fn)` | Supply something the server does not have. First answer wins. |

`rdio.definePoint(name)` publishes a point of your own, so other plugins can
extend yours.

Registering against a point that does not exist is an error, rather than a
handler that silently never runs.

A `filter` or `provide` handler that times out, throws, or returns something
unusable is treated as having done nothing, and whatever it was given passes
through unchanged. `override` is the exception: replacing behaviour means
owning its failures, because there is no original left to fall back to.

## Extension points

### Lifecycle

| Point | Timeout | Notes |
|---|---|---|
| `startup` | default | After the plugin loads and its tables exist. |
| `shutdown` | default | The server is stopping. Best effort. |
| `tick` | default | Hourly, alongside the built-in maintenance run. |
| `config.changed` | default | This plugin's settings were saved. |
| `client.connect` | default | A listener connected. |
| `client.disconnect` | default | A listener disconnected. |

### Ingest

| Point | Timeout | Notes |
|---|---|---|
| `call.receive` | default | A call arrived, before anything has been decided about it. |
| `call.accept` | default | Whether to accept the call at all. Veto to discard it. |
| `call.duplicate` | default | Whether the call is a duplicate of one already stored. |
| `call.convert` | default | Audio conversion. Override to replace ffmpeg entirely. |
| `call.store` | default | Last chance before storage: modify, replace the audio, or drop. |
| `call.stored` | default | The call has an id. Where most work belongs. |

### Delivery

| Point | Timeout | Notes |
|---|---|---|
| `call.delay` | default | How long to hold the call before listeners see it. |
| `call.emit` | 250ms | Per listener, before delivery. Redact or withhold. |
| `call.payload` | 250ms | The JSON shape a client receives. |
| `call.emitted` | default | The call has been sent to listeners. |
| `downstream.send` | default | Per downstream, before forwarding. |
| `client.config` | 250ms | The configuration payload each client receives. |

### Access

| Point | Timeout | Notes |
|---|---|---|
| `access.check` | default | Validate an access code. Provide to authenticate elsewhere. |
| `access.scope` | 250ms | What systems and talkgroups a session may see. |
| `apikey.check` | default | Validate an API key used for uploads. |
| `admin.check` | default | Validate an admin session. |

### Data

| Point | Timeout | Notes |
|---|---|---|
| `call.search` | 2s | Search predicates and results. |
| `call.prune` | default | Whether a call may be deleted by retention. |
| `call.audio` | default | Supply a call's audio when the server has none stored. |
| `config.save` | default | Configuration is being saved. |

## Configuration models

`rdio.models.<name>` reads and writes the server's configuration. Each one
offers `list()`, `get(id)`, `set(entry)` and `remove(id)`. Entries are the same
shape the admin panel uses.

### `rdio.models.systems`

Radio systems, with their talkgroups and units.

Fields: `_id`, `alert`, `autoPopulate`, `blacklists`, `delay`, `id`, `label`, `led`, `order`, `talkgroups`, `units`

Identified by `_id`.

### `rdio.models.groups`

Talkgroup groupings shown in the selector.

Fields: `_id`, `label`

Identified by `_id`.

### `rdio.models.tags`

Talkgroup tags shown in the selector.

Fields: `_id`, `label`

Identified by `_id`.

### `rdio.models.access`

Access codes and the systems each one unlocks.

Fields: `_id`, `code`, `expiration`, `ident`, `limit`, `order`, `systems`

Identified by `_id`.

### `rdio.models.apikeys`

API keys accepted for call uploads.

Fields: `_id`, `disabled`, `ident`, `key`, `order`, `systems`

Identified by `_id`.

### `rdio.models.downstreams`

Other Rdio Scanner servers calls are forwarded to.

Fields: `_id`, `apiKey`, `disabled`, `order`, `systems`, `url`

Identified by `_id`.

### `rdio.models.dirwatches`

Watched directories that calls are ingested from.

Fields: `_id`, `delay`, `deleteAfter`, `directory`, `disabled`, `extension`, `frequency`, `mask`, `order`, `systemId`, `talkgroupId`, `type`, `usePolling`

Identified by `_id`.
